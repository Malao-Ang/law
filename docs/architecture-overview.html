ไปป์ไลน์การสกัด OCR ของ Python

1
จำแนกประเภทไฟล์
detect_file_type(path)
ผลลัพธ์: docx · pdf_text · pdf_scan · mixed
2
สกัดข้อความ
DoclingService.extract() / extract_mixed_pdf()
DOCX: parse XML ผ่าน docx_parser. PDF text: docling-parse (bbox-accurate). ตาราง: Docling TableFormer (do_cell_matching=True). รูปภาพ: crop ไปยัง poc/images/
⚡ Fast mode: PHP FastDocxExtractor สำหรับ DOCX ทั่วไป
3
OCR (หน้าที่สแกนมา)
OcrPipeline.extract() · LandingAiAdeParser.parse_pdf()
Mode local: EasyOCR (โหลดแบบ lazy, ใช้ GPU ถ้ามี). Mode landingai: ADE Parse API → Markdown → blocks. Mode auto: ลอง LandingAI ก่อน
⚠ Quality gate (auto mode): mean_confidence < 0.78 หรือ uncertain_ratio > 0.50 → fallback ไป EasyOCR
4
วิเคราะห์ Layout
infer_indent_levels(pages)
จัดกลุ่ม x-position ทั้งเอกสาร กำหนด indent_level 0–7 ต่อบล็อก
5
กำหนด Indent เชิงความหมาย
resolve_semantic_indents(pages)
ใช้กฎกฎหมายไทยหลัง geometry pass: มาตรา → level 0, ข้อ → level 1, วรรค/ข้อความต่อเนื่องรับ indent จากแม่, เส้นคั่น → โดย pattern
⚡ ห้ามข้ามสำหรับ PDF กฎหมาย
6
จำแนกเลขลำดับ
NumberingTokenizer.annotate()
ตรวจหารูปแบบ มาตรา / ข้อ / วรรค / (ก) / ๑.๑ เขียน list_marker.{type, level, text} ลงใน block meta
7
ปรับมาตรฐานภาษาไทย
normalize_text(text) → NormalizeResult
จัดลำดับสระ, แก้ไขวรรณยุกต์, ํา → ำ, ทำความสะอาด whitespace (เก็บ \t และ \n ไว้). NormalizeResult TypedDict: {normalized, changes}
8
ตรวจสอบการสะกด (opt-in)
ThaiSpellChecker.check(text)
Lazy singleton. NorvigSpellChecker + resources/legal_terms.txt. ทำงานเฉพาะบล็อกที่ needs_review=True ควบคุมโดย THAI_REVIEW_THRESHOLD (ค่าเริ่มต้น 0.90)
9
แก้ไขด้วย AI (opt-in)
MockAICorrector.correct()
เชื่อมต่อ provider จริงได้ที่ services/ai_corrector.py. ส่งเฉพาะบล็อก needs_review=True เขียนชั้น ai_suggested_text
10
ประกอบเอกสาร
build_document_output(pages, meta)
ประกอบบล็อก 4 ชั้น เขียน {id}.review.json ไปยัง intermediate/
11
Callback
_post_callback(callback_url, id, payload)
POST ไปยัง INTERNAL_CALLBACK_URL (Laravel). Dual-write: ข้อผิดพลาดบันทึกทั้งในไฟล์ JSON และ callback. LandingAI metadata: job_id, duration_ms, credit_usage, failed_pages
