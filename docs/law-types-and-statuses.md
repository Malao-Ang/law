# ประเภทกฎหมายและสถานะ

เอกสารนี้สรุปค่าหลักที่ใช้กับ `LawMeta` สำหรับผู้เขียนและผู้พัฒนา อ่านคู่กับ
[`law-metadata-reference.md`](law-metadata-reference.md) เมื่อต้องตัดสินว่า field ใดเป็น canonical
หรือ derived

## ประเภทเอกสาร

ประเภทเอกสารเป็น master data 2 ระดับ:

```text
กลุ่มประเภท (law_family / LFMxx)
  -> ประเภทเอกสาร (law_type / LTYxx)
```

`law_meta.law_type` เก็บเฉพาะ code ของประเภทเอกสาร (`LTYxx`) เท่านั้น ส่วนกลุ่ม (`LFMxx`) ใช้เพื่อ
จัดหมวด สีป้าย ที่มา ภายใน/ภายนอก หน่วยนับ และ filter ระดับกลุ่ม

| กลุ่ม | ที่มา · หน่วย | ประเภทเอกสาร |
|---|---|---|
| `LFM01` ข้อบังคับ | ภายใน · ข้อ | `LTY03` ข้อบังคับ |
| `LFM02` ระเบียบ | ภายใน · ข้อ | `LTY02` ระเบียบ |
| `LFM03` ประกาศ | ภายใน · ข้อ | `LTY01` ประกาศที่ออกโดยมหาวิทยาลัย, `LTY09` ประกาศที่ออกโดยสภามหาวิทยาลัย |
| `LFM04` กฎหมายภายนอก | ภายนอก · มาตรา | `LTY04` พระราชกำหนด, `LTY05` พระราชบัญญัติ, `LTY06` กฎกระทรวง, `LTY07` ประกาศกระทรวง, `LTY08` กฎหมายภายนอกอื่น ๆ |

ไม่มี master `issuer` แล้ว และไม่มี `requires_issuer` แล้ว ผู้ออกประกาศถูกพับเข้าไปอยู่ในชื่อประเภท
เอกสาร เช่น `LTY01` และ `LTY09`

## Alias และค่าเก่า

| ค่าเก่า | map ไป |
|---|---|
| `คำสั่ง`, `ประกาศที่ออกโดยมหาวิทยาลัย` | `LTY01` |
| `มติ`, `ประกาศที่ออกโดยสภามหาวิทยาลัย` | `LTY09` |
| `พ.ร.บ.`, `พรบ` | `LTY05` |

ค่า `ประกาศ` เฉย ๆ เป็น alias ของกลุ่ม `LFM03` เท่านั้น ไม่ใช่ประเภทเอกสาร และห้ามเดาเป็น
`LTY01` โดยอัตโนมัติ การแสดงผลจะใช้ label `ประกาศ (ยังไม่ระบุผู้ออก)` เพื่อให้รู้ว่าต้องแก้ผ่านฟอร์ม

## Migration: NEEDS_FORM

คำสั่ง migrate law type จะไม่เขียนทับเอกสารที่เป็น `ประกาศ` เฉย ๆ หรือ legacy `LTY01` ที่ไม่มี
legacy issuer ที่ชัดเจน แต่จะรายงานเป็น `NEEDS_FORM` พร้อม document id และ title แล้ว exit 0

กรณีที่ยัง map ได้:

- `ประกาศ`/`LTY01` + legacy `มหาวิทยาลัย`/`ISS01` -> `LTY01`
- `ประกาศ`/`LTY01` + legacy `สภามหาวิทยาลัย`/`ISS02` -> `LTY09`

## กติกาความสัมพันธ์

กติกาพิเศษผูกกับ code เท่านั้น:

- `LTY09` เลือกกฎหมายแม่ได้จาก พ.ร.บ./กฎหมายภายนอก ระเบียบ ข้อบังคับ และประกาศ
- `LTY01` เลือกกฎหมายแม่ได้เฉพาะระเบียบและข้อบังคับ
- ประเภทอื่น รวมถึง `ประกาศ` เฉย ๆ และประเภทที่ admin เพิ่มเอง ไม่มีข้อจำกัดพิเศษ

## ที่มาและหน่วยนับ

- กลุ่มภายใน (`internal`) ใช้คำว่า `ข้อ`
- กลุ่มภายนอก (`external`) ใช้คำว่า `มาตรา`
- หน้า law-info แสดง hint ใต้ประเภทเอกสาร เช่น `ภายใน · นับเป็น "ข้อ"`

## สถานะหลัก

| Field | ความหมาย |
|---|---|
| `status` | สถานะบังคับใช้ทางกฎหมาย |
| `published_date` | ว่าง = ยังไม่เผยแพร่, มีวันที่ = เผยแพร่แล้ว |
| `access_scope` | ใครเห็นเอกสาร |
| `change_status` + `change_details` | เปลี่ยนแปลงอะไรจากเวอร์ชันก่อน |

ทั้ง 4 แกนเป็นอิสระต่อกัน ยกเว้นขั้น publish หลัง e-sign ที่ตั้ง `status` เป็นมีผลบังคับใช้และเติม
`published_date`

## สรุปสั้น

- ชนิดเอกสาร = `law_type` (`LTYxx`) ใต้ `law_family` (`LFMxx`)
- สี ที่มา หน่วยนับ และ section/filter ระดับหน้าบ้าน derive จาก `law_family`
- ผู้ออกประกาศอยู่ในประเภทเอกสารแล้ว ไม่มี field ให้เลือกแยก
- `ประกาศ` เฉย ๆ ต้องให้ผู้ใช้เลือก `LTY01` หรือ `LTY09` เอง
